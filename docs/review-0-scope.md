# Review 0 Scope

## Problem
Retail managers may need to combine future demand, current inventory, expiry, supplier information, previous purchases and procurement policies before deciding what and how much to order.

## Research gap
Individual technologies such as machine learning forecasting, RAG and LLMs already exist. The project focuses on integrating them into a unified retail procurement decision-support workflow with human approval.

## Contribution
- Demand prediction using XGBoost.
- Context-aware demand signals including festival, weather and day patterns.
- Expiry-aware inventory support.
- Supplier intelligence using relevant business information.
- Organization-specific RAG retrieval.
- Explainable LLM-based procurement recommendation.
- Human-in-the-loop manager approval.
- Purchase-order drafting and tracking.
